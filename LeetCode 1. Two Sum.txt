LeetCode 1. Two Sum
Problem Statement

Given an array of integers nums and an integer target, return the indices of the two numbers such that they add up to target.
You may assume that each input would have exactly one solution, and you may not use the same element twice.
You can return the answer in any order.

Example:
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: nums[0] + nums[1] = 2 + 7 = 9

Approach

The most efficient approach uses a hash map. While iterating through the array, for each number we calculate the value needed to reach the target (i.e., target - current number). Before storing the current number in the map, we check whether this required value already exists in the map. If it does, we have found the two indices that add up to the target. This approach works in one pass, avoids nested loops, and ensures optimal performance.

JavaScript Code (LeetCode Ready)
var twoSum = function(nums, target) {
    let map = new Map();

    for (let i = 0; i < nums.length; i++) {
        let complement = target - nums[i];

        if (map.has(complement)) {
            return [map.get(complement), i];
        }

        map.set(nums[i], i);
    }
};
