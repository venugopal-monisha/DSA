8. Merge Sorted Array

Problem Statement:
You are given two sorted arrays nums1 and nums2. Merge nums2 into nums1 as one sorted array.

Approach:
Start merging from the end to avoid overwriting values in nums1. Compare elements from the back of both arrays and place the larger one at the end.

JavaScript Code:

var merge = function(nums1, m, nums2, n) {
    let i = m - 1, j = n - 1, k = m + n - 1;

    while (j >= 0) {
        if (i >= 0 && nums1[i] > nums2[j]) {
            nums1[k--] = nums1[i--];
        } else {
            nums1[k--] = nums2[j--];
        }
    }
};
