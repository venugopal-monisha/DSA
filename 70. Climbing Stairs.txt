70. Climbing Stairs

Problem Statement:
You can climb 1 or 2 steps. Find the number of distinct ways to reach the top.

Approach:
This follows Fibonacci logic. Each step depends on the previous two.

JavaScript Code:

var climbStairs = function(n) {
    if (n <= 2) return n;

    let a = 1, b = 2;
    for (let i = 3; i <= n; i++) {
        let c = a + b;
        a = b;
        b = c;
    }
    return b;
};
