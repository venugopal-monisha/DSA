69. Sqrt(x)

Problem Statement:
Given a non-negative integer x, return the square root of x rounded down to the nearest integer.

Approach:
Binary search is applied between 1 and x. For each mid value, compare mid * mid with x. Adjust the search space until the closest integer square root is found.

JavaScript Code:

var mySqrt = function(x) {
    if (x < 2) return x;

    let left = 1, right = x, ans = 0;

    while (left <= right) {
        let mid = Math.floor((left + right) / 2);
        if (mid * mid <= x) {
            ans = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return ans;
};
