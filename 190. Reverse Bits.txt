190. Reverse Bits

Problem Statement:
Reverse bits of a given 32-bit unsigned integer.

Approach:
Process the integer bit by bit for 32 iterations. Shift the result left and append the last bit of the number in each iteration.

JavaScript Code:

var reverseBits = function(n) {
    let result = 0;
    for (let i = 0; i < 32; i++) {
        result = (result << 1) | (n & 1);
        n = n >>> 1;
    }
    return result >>> 0;
};
