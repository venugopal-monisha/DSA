191. Number of 1 Bits

Problem Statement:
Return the number of 1 bits in the binary representation of a number.

Approach:
Using the operation n & (n - 1) removes the lowest set bit. Repeating this until n becomes zero gives the count of 1 bits. This is faster than checking every bit.

JavaScript Code:

var hammingWeight = function(n) {
    let count = 0;
    while (n !== 0) {
        n = n & (n - 1);
        count++;
    }
    return count;
};
